## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| contributor change to protected branch | untrusted code and files reach the repo through commits and pull requests |
| CI runner to third-party actions and downloaded binaries | mutable tags and unverified downloads can run attacker code with repo access |
| CI logs to the public or team | scanner and test output is readable beyond the runner |
